Administration → Settings controls how AssetLotse works for you. Don't forget Save at the bottom.

The page is divided into five tabs. The one you had open stays open after saving.

  • General
    • Name (organisation or program) – shown everywhere, “AssetLotse” by default; Default language (currently {{ f.languages.get(f.default_language, f.default_language) }}) – used for visitors whose browser prefers neither German nor English, and for emails to users who have not chosen a language.
  • Inventory & issuing
    • Inventory visibility: {% if f.catalog_own %}currently staff members see no inventory, only their own items (default){% elif f.catalog_all %}currently everyone sees the whole inventory{% else %}currently staff members only see their groups' items and general items{% endif %}. Issuing is always limited to a person's own groups.
    • Issuing: Default loan period (days) – currently {% if f.loan_days %}{{ f.loan_days }} {{ "day" if f.loan_days == 1 else "days" }}{% else %}0 = open-ended (the default; open-ended loans are never overdue, get no reminders and need no extending){% endif %}. Managers can override it when issuing. Extension by {{ f.extension_days }} {{ "day" if f.extension_days == 1 else "days" }}, at most {{ f.max_extensions }} {{ "time" if f.max_extensions == 1 else "times" }}; Max. items per person {% if f.max_loans %}{{ f.max_loans }}{% else %}unlimited (0){% endif %}.
    • Self-service: Self-checkout ({{ "on" if f.self_checkout else "off" }}), Self-service extension ({{ "on" if f.self_extend else "off" }}), Self-return ({{ "on" if f.self_return else "off" }}). Whatever is off is done by managers.
  • Accounts
    • Self-registration – see its own topic.
  • Security
    • Two-factor authentication – requirement and internal network, see its own topic. This is also where you switch Allow signing in with a passkey on or off (default: on). A passkey replaces password and second factor; Active Directory accounts can only use it when a service account is set up, because AssetLotse checks in AD at every passkey sign-in whether the account is still active.
    • Automatic sign-out – after how many hours without activity people are signed out: For everyone (default 12, start value from ASSETLOTSE_SESSION_HOURS; 0 = off), optionally shorter For administrators and From outside. The shortest limit that applies wins. Plus the notice 2 minutes before and Sign out when the browser is closed (then there is no “Stay signed in”). For you it is currently: {% if f.idle_minutes %}{% if f.idle_minutes % 60 %}{{ f.idle_minutes }} minutes{% else %}{{ f.idle_minutes // 60 }} {{ "hour" if f.idle_minutes == 60 else "hours" }}{% endif %}{% else %}no automatic sign-out{% endif %}.
    • Internal network – which connections count as internal (own networks, own internet connection); used by the two-factor rules and by the automatic sign-out for access from outside. At the bottom of the section you see how your current connection is classified.
  • Privacy
    • Legal: addresses of the Legal notice and Privacy policy. The links appear on the sign-in page, in the sidebar and in every email.
    • Retention – deletion period for completed loans, currently {% if f.retention_months %}{{ f.retention_months }} {{ "month" if f.retention_months == 1 else "months" }}{% else %}never{% endif %}.

Important – the secret_key file: it lives in the data folder (./data/secret_key) and belongs inseparably to the database. It encrypts 2FA secrets, SMTP and AD passwords and the items' confidential details (e.g. BitLocker keys). If it is lost or does not match the database, this data becomes unreadable. So always back it up as well.
