In the Inventory, the CSV button at the top right downloads the inventory as a spreadsheet (assetlotse-inventory.csv) – e.g. for a stocktake. It contains {% if current_user.is_global_manager %}all items{% else %}the items of your groups and general items{% endif %}, sorted by name – search and filter settings make no difference.

Columns: ID, Name, Category, Manufacturer, Model, Serial number, Inventory number, Location, Group (or “General”), Quantity, Available, Issued to.

  • The file is Excel-compatible: semicolon as separator and UTF-8 with a byte-order mark so that umlauts display correctly. A double-click is enough.
  • Formula protection: cells starting with =, +, - or @ get a leading apostrophe. This stops Excel from running anything as a formula; you may see the apostrophe in the cell.
  • Personal data: the “Issued to” column shows who currently has the item, so handle the file with care. Confidential details (e.g. BitLocker keys) are never included.

The ID is the internal number you can enter at the Issue desk as #ID.
