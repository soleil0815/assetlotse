Under Management → Locations you define rooms, cabinets or compartments once. As soon as there is at least one, the location is picked from a list instead of typed when adding or editing an item – no more typos.

  • Add: type the names into the field, one per line, then click Add. Duplicate names (including different capitalisation) are skipped.
  • Rename: change the name in the field and save with ✓ – all items at this location are updated too. An optional note helps people find it (e.g. “keys at the front office”).
  • Deleting is only possible once no item is assigned there any more.
  • The number next to each location leads to the items there; the Inventory can be filtered by location.

In use but not defined lists locations that were typed freely in the past. Choose add as new location or replace with … and click Apply – the items are moved along with it. For a different spelling (“room 2.14”) or a similar name (“Rom 2.14”) the matching location is already preselected.

Merging: two defined locations cannot be merged by renaming. Move the items of one of them and then delete it.
